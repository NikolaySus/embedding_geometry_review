# Компактная статья: первая компоновка с dense-рисунками

## Статус

Редакция изменяет `manuscript/compact.md`, без создания параллельной рукописи.
Полная статья, экспериментальные данные, обучение и оценка не изменены.
Историю редакций хранит Git. Ракурсы и размеры шрифтов взяты из текущих
dense-вариантов галереи без подбора новых параметров.

Сборка: `uv run python src/build_article.py --variant compact`.
Проверка: `uv run python src/validate_publication.py --variant compact`.
Результаты находятся в `build/compact/` и не включаются в Git.
Сборка не требует предварительного создания галереи или интерактивного HTML.

| Показатель | До изменения | Текущая компоновка |
|---|---:|---:|
| Страницы PDF | 14 | 18 |
| Слова по валидатору | 4043 | 4492 |
| Рисунки | 4 | 5 |
| Таблицы | 5 | 6 |

Это первая попытка интеграции более содержательных рисунков, а не достигнутое
сокращение объёма. Название compact обозначает вариант рукописи, а не гарантию
меньшего объёма относительно предыдущей редакции. Приоритетом было сохранение
содержания; дальнейшее уплотнение требует отдельного решения по компоновке.

## Выбранные рисунки

| Номер | Идентификатор галереи | Содержание |
|---|---|---|
| 1 | `1C-09-absolute-unit-dense` | Абсолютное качество и геометрия второго этапа, включая M0, средние и SD |
| 2 | `2D-compact-dense` | Изменения геометрии на симплексе целей |
| 3 | `3E-compact-dense` | Изменения качества независимых семейств задач |
| 4 | `4A-compact-dense` | Геометрические траектории первого этапа |
| 5 | `5A-compact-dense` | Нелинейные остатки смешивания целей |

Ширина каждого изображения в DOCX равна 6,2 дюйма. Генератор статьи вызывает
те же функции визуализации, что и галерея. Параметры экспериментов и статистика
не меняются. Тесты сравнивают изображения с результатом прямого вызова функций
галереи пиксель в пиксель и проверяют независимость от её выходного каталога.

## Сохранение информации

| Предыдущее представление | Текущее расположение информации |
|---|---|
| Схема дизайна опыта | Методы: четыре пары «корпус — функция потерь», независимые старты от M0, этапы и бюджет |
| Сводный график качества и геометрии | Абсолютная матрица и две карты симплекса; обе таблицы первого этапа сохранены |
| Диагностические графики корреляций | Текст: r = 0,942 и r = 0,823, n = 12, оговорка об отсутствии причинного доказательства; геометрические траектории вынесены в рисунок 4 |
| График компромиссов и нелинейного эффекта | Списки точек двух фронтов Парето, карта остатков и таблица трёх примеров со средними и SD |

Численные свидетельства сохранены, однако визуальное представление отдельных
облаков корреляций и фронтов Парето больше не воспроизводится в статье.
Их исходные числовые данные остаются в репозитории. Новое внешнее приложение
не создавалось: все необходимые для аргументации примеры находятся в тексте.
Семейные показатели двух этапов не подменяются друг другом: во втором этапе
AG News отделена от переноса классификации на другие задачи.

## Ограничения компоновки

Ракурсы поверхностей намеренно не исправлялись в этой итерации. Унаследованные
сближения и частичные наложения числовых подписей требуют последующего подбора
ракурсов. Поверхности соединяют измеренные точки, а не представляют дополнительные
эксперименты. Высота верхнего слоя чисел условна. SD на поверхностях не показан;
его нельзя восстанавливать по цвету или высоте поверхности.

Крупные неделимые рисунки оставляют свободное место на отдельных страницах.
Таблица абсолютных показателей первого этапа продолжается на следующей странице.
В дальнейшем можно отдельно оптимизировать разрывы страниц и подписи, но не
уменьшать читаемость чисел ради формального сокращения числа страниц.

## Воспроизводимость

`build/compact/data/figure_manifest.json` фиксирует выбранные рисунки и размеры.
Там же сохраняются численные таблицы, корреляции, фронты Парето и примеры остатков.
Валидатор сверяет числовые примеры с данными, число таблиц и рисунков, порядок
изображений, их ширину и отсутствие редакционных комментариев в публикации.

Дополнительные проверки:

```bash
uv run pytest -q
uv run python scripts/verify_migration.py
uv run python scripts/check_source_checkout.py
git diff --check
```

Последняя команда сборочной проверки создаёт отдельную служебную копию только
из доступных Git исходников и собирает обе статьи и галерею без старых артефактов,
без GPU и с отключённым доступом к Hugging Face.
