# Редакция по единому эксперименту

## Источник и границы изменений

Обе рукописи и галерея по умолчанию используют только
`english_geometry_unified_v1`, модель `all_minilm`.
Источник закреплён в `configs/publication.json`: идентификатор опыта, модель,
хеш протокола. Исторические эксперименты сохранены, но не подмешиваются к
новым результатам. Нового обучения и оценки при подготовке документов нет.

Чистые специализации теперь являются вершинами того же симплекса смесей.
Дублирующие разделы первого и второго этапов удалены. AG News везде отделена
от независимого переноса классификации. Общая M0 оценена один раз; её
повторение в CSV не означает повторного опыта.

## Состав

| Материал | До переработки | Новая редакция |
|---|---|---|
| Compact | 18 страниц, 5 рисунков, 6 таблиц | 14 страниц, 5 рисунков, 3 таблицы |
| Full | 22 страницы, 12 рисунков | 19 страниц, 11 рисунков, 7 таблиц |
| Галерея | Исторические два этапа | Единый эксперимент; сохранены 10 вариантов и 12 интерактивных панелей |

Точное число страниц и слов печатает валидатор после сборки. На первой
сборке compact получено 14 страниц без уменьшения шрифтов.

Compact: абсолютная матрица; геометрия симплекса; качество симплекса;
траектории gate STS/поиска и ранга/соседств; остатки смешивания.
Full дополнительно содержит дизайн, аудит, пять траекторий качества,
четыре траектории геометрии, полный конечный спектр, две диаграммы
описательных корреляций и три фронта Парето.

Ракурсы поверхностей и интерактивные настройки сохранены. Числовые подписи
на трёхмерных поверхностях местами сближаются; дальнейший подбор ракурсов
остаётся отдельной задачей. Полные точные значения доступны в CSV.
Ширина изображений в DOCX остаётся 6,2 дюйма. Строки таблиц теперь не
разрываются между страницами.

## Существенные научные уточнения

- Контроль даёт чуть больший средний прирост STS, чем чистая STS-цель.
- Чистая поисковая цель не улучшает независимый поисковый агрегат.
- Классификация по AG News не равнозначна переносу классификации.
- Корреляция ранг–STS по 12 конечным состояниям равна 0,9463,
  без чистой классификации (9 состояний) — −0,0899.
- Корреляция зазор–поиск составляет соответственно 0,8247 и 0,9455.
- Корреляции описательные, не причинные; временные точки не объединяются
  в псевдонезависимую выборку.
- Ни один обученный режим не сохраняет средние всех четырёх семейств.
- Gate и полная оценка не смешиваются внутри одной траектории.
- Аудит точных совпадений не доказывает отсутствия всех видов пересечения.

## Воспроизводимость

`src/publication/unified_assets.py` строит рисунки и экспортирует evidence.
Численные вставки вида `{{R0}}` и генерируемые Markdown-таблицы в рукописях
разрешаются при сборке. Полный читаемый Markdown с числами находится в
`build/{variant}/manuscript.md`. Редактировать следует исходные рукописи,
а не выходы сборки.

В `build/{variant}/data/` сохраняются CSV, JSON, манифест рисунков и
`provenance.json` с SHA-256 всех использованных численных источников.
Сборка каждой статьи автономна: предварительно строить галерею не нужно.
Историческая галерея доступна явно через
`uv run python src/build_gallery.py --experiment historical`.

```bash
uv run python src/build_article.py --variant full
uv run python src/build_article.py --variant compact
uv run python src/build_gallery.py
uv run python src/validate_publication.py --all
uv run pytest -q
uv run python scripts/verify_migration.py
uv run python scripts/check_source_checkout.py
```

Последняя проверка собирает документы только из видимых Git исходников,
без весов, корпусов, старых результатов сборки и GPU.
