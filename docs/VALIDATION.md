подтверждает отсутствие необходимости в прежних артефактах, но не является
испытанием на другой ОС или с другими версиями шрифтов и рендереров.

Общий объём предназначенных для Git материалов составляет примерно 11 МБ;

0,8 МБ. Модельные веса, окружение и сгенерированные материалы в этот объём
не входят. `git add --dry-run .` проверен; реальное добавление в индекс,
коммит и push не выполнялись.

## Повторение проверок

```bash
uv run pytest
uv run python scripts/verify_migration.py --include-local
uv run python src/validate_publication.py --all
uv run python scripts/check_source_checkout.py
```

Последняя команда автоматически пересоздаёт только свой временный каталог
`build/source-checkout-check/` и оставляет там журнал каждого этапа и
`validation.json`. Исходные результаты исследования не перезаписываются.

Подробные локальные свидетельства проверки находятся в игнорируемом `build/`:

- `publication-validation.md`: сравнение статей, таблиц и рендеров;
- `gallery/parity/static-parity.json`: попиксельное сравнение 17 вариантов;
- `gallery/validation.json`: числовые и структурные проверки галереи;
- `gallery/browser-check.log`: проверка интерактивных панелей в браузере;
- `source-checkout-check/validation.json`: сборка из чистого набора исходников.

Полное бинарное совпадение PDF/DOCX не требуется: контейнеры могут содержать
временные метки. Изменены технические пути и заголовки оглавления галереи,
но не исследовательские результаты и не сами варианты рисунков.

Перенос не является новым раундом оптимизации оформления галереи. Унаследованные
пересечения отдельных числовых подписей при некоторых ракурсах и увеличенном
шрифте не устранялись изменением данных или расположения точек. Для подготовки
публикационного рисунка по-прежнему требуется выбрать подходящий ракурс и размер
подписей и визуально проверить экспорт.
