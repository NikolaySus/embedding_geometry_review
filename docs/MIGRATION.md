# Перенос исследования

## Откуда и что перенесено

Исходное исследование:
`/home/nop/Documents/m2/research/gigachat-test/articles/embedding_geometry_review`.
Новый самостоятельный репозиторий:
`/home/nop/Documents/m2/research/embedding_geometry_review`.

Исходная директория сохраняется без изменений. Перенос не включает новые запуски
обучения или оценки, изменение обучающих целей, корректировку метрик и пересмотр
выводов. Копируются имеющиеся данные; отсутствующие веса не восстанавливаются.

Код `src/embedding_geometry/`, CLI `src/experiment.py`, исходные конфигурации,
результаты `runs/`, отчёты `reports/`, библиография, подготовленные корпуса,
исходные тесты и файлы зависимостей сохранены побайтово. Проверка и перечень файлов
находятся в `migration_manifest.json`. Поле `storage` различает материалы для
Git и тяжёлые локальные артефакты.

Пути в исторических отчётах и метаданных не переписываются. Упоминания прежних
каталогов `assets/experimental_v*` следует читать как историческое происхождение:
актуальные входы и выходы сборки описаны ниже и в README.

соответствий. Изменения путей и технических имён не должны менять числа,
математический смысл, порядок вариантов и интерактивные возможности.

## Самостоятельность и большие файлы

Новый `.venv` создаётся через `uv sync --locked`; прежнее окружение не копируется.
Корпуса и имеющиеся веса скопированы локально. В Git входят метрики и манифесты,
но не корпуса, модельные экспорты или кэшированные массивы эмбеддингов.

Генераторы используют только файлы нового репозитория. Исходная директория нужна
лишь для необязательной сверки переноса:

```bash
uv run python scripts/verify_migration.py --include-local \
  --source /home/nop/Documents/m2/research/gigachat-test/articles/embedding_geometry_review
```

Для обычной проверки достаточно команды без `--source`. Игнорируемые артефакты
не требуются для сборки статьи из сохранённой статистики. Для повторного обучения
на другой машине потребуется заново подготовить данные или отдельно перенести
локальные файлы; Git не служит хранилищем весов и корпусов.

Все выходы публикационной сборки находятся в `build/`. Исходные CSV/JSON и
выбранные настройки камер находятся вне этого каталога и доступны для Git.
Проверки `.gitignore` проверяют как синтетические пути, так и все записи
миграционного манифеста. В частности, `runs/` и журналы не игнорируются целиком.

## Границы проверки

Сверка SHA-256 подтверждает сохранность существующих результатов, но не заменяет
научную валидацию дизайна эксперимента. Существующие ограничения, аудиты
пересечений и правила отбора наблюдений остаются в силе.

Совпадение числовых данных обязательно; побайтовое совпадение DOCX/PDF не
требуется, поскольку контейнеры и рендереры могут включать временные метки.
Сохранение оформления проверяется по структуре документов и рендерам страниц.

Перенос подготавливает рабочее дерево. Коммит и публикация на GitHub выполняются
только после отдельного решения автора.
