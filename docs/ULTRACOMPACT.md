# Ультракомпактная статья и доклад

Статья рассчитана на **6 страниц целиком**, включая русские и английские сведения,
пять рисунков, десять источников и декларацию об использовании ИИ. Правила из
`rules/` имеют приоритет над отдельными параметрами примеров оформления:
A4, поля 2 см, Times New Roman 12 pt, интервал 1,5. Разделы: введение, материалы
и методы, результаты, обсуждение, заключение. Данные автора находятся в
`configs/conference.json`.

Секция: «Анализ и обработка естественного языка, графов, машинное обучение».
УДК `004.912:004.85` отражает обработку текста в связи с машинным обучением
([004.912](https://www.triumph.ru/html/serv/udk.html?category_id=1023&endpoint=1),
[004.85](https://teacode.com/online/udc/00/004.8.html)). Текстовые абзацы,
включая названия и сведения об авторе, выровнены по ширине;
короткие абзацы и последние строки начинаются слева. Рисунки и подписи к ним
центрированы. Шрифты текста и темы DOCX явно заданы как Times New Roman,
включая заголовки; длинные тире заменяются средними (–).

Исходник — `manuscript/ultracompact.md`.
Обе аннотации и оба списка из девяти ключевых слов восстановлены дословно
из `manuscript/compact.md`; английская аннотация продолжается на второй странице.
Библиография выбирается из общего списка по устойчивым идентификаторам
и перенумеровывается только в этой статье, по первому появлению ссылок в тексте.
Десятым источником возвращена работа Yu et al. о PCGrad: в обсуждении она
обозначает направление дальнейшей проверки, а не установленный механизм результатов.
Исходники full, compact и галереи не изменяются. Научные данные поступают из
завершённого `english_geometry_unified_v1`; сборка не запускает обучение.

Все пять рисунков и их числовые подписи сохранены. Поверхности в статье расположены
с высотой камеры 40° и азимутом 180° (выбранный вариант 4): сторона STS–Ret
проецируется вертикально справа. Подписи STS, Cls и Ret вынесены наружу
от соответствующих вершин. Этот же ракурс используется в презентации;
на четырёх внутренних делениях ближнего ребра указаны доли STS, Cls, Ret
сверху вниз, в процентах (шаг 20%; на этом ребре Ret равен нулю).
Настройки `surface_elevation` и `surface_azimuth` хранятся в `configs/conference.json`.
Панели поверхностей расположены по четыре в ряд. При ширине ряда 6,2 дюйма подписи мелкие; векторные PDF
отдельных рисунков позволяют рассмотреть их с увеличением. Соединяющие грани
не означают дополнительных измерений. На поверхностях SD не показано;
на траекториях сохранены полосы SD.

## Презентация

`assets/presentation/slides.json` задаёт шесть слайдов: титульный и по одному
рисунку на каждом из остальных. Сборщик использует титульный фон и боковую
панель предоставленного шаблона `rules/of.prezentaciya_russkiy_inzhener_shablon.pptx`.
Формат 16:9. Вместо недоступного ALS Sector используется Arial. Заголовки
редактируемые; научные рисунки встроены как PNG, их отдельные PDF сохраняются рядом.
Для поверхностей использована компоновка 2 × 2 с сохранением измеренных точек,
ракурсов, шкал и числовых меток.

`manuscript/talk.md` — отдельный текст выступления примерно на 10–12 минут.
Его DOCX содержит шесть разделов по слайдам и пометки докладчику. Текст не
добавляется в заметки PowerPoint.

## Сборка и проверка

```bash
uv sync --locked
uv run python src/build_article.py --variant ultracompact
uv run python src/validate_publication.py --variant ultracompact
uv run python src/build_talk.py
uv run python src/validate_talk.py
uv run pytest tests/test_ultracompact.py tests/test_conference.py tests/test_repository_policy.py -q
```

Нужны LibreOffice, Poppler и браузер для Kaleido. Презентация дополнительно
использует Node.js, `@oai/artifact-tool` и валидаторы навыка presentations из
установленного Codex runtime. Пути можно переопределить переменными
`PRESENTATION_NODE`, `PRESENTATION_MODULES`, `PRESENTATION_PYTHON`,
`PRESENTATION_SKILL`. На Windows каталог LibreOffice должен входить в PATH.
Для тестов без графического интерфейса задайте `MPLBACKEND=Agg`.
Если окружение публикации уже подготовлено, `uv run --no-sync` позволяет
не загружать зависимости обучения; основной `uv.lock` не меняется.

Выходы, изображения, проверки и provenance находятся только в игнорируемом `build/`:

- `ultracompact/cross_task_interference_ultracompact.docx` и `.pdf`;
- `presentation/cross_task_interference_talk.pptx` и `.pdf`;
- `presentation/speaker_script.docx`;
- `presentation/validation.json` и `presentation-validation/receipt.json`.

Проверка доклада сопоставляет числовые подписи всех пяти рисунков со статьёй,
проверяет число слайдов, формат, сведения автора и хеши исходников. После сборки
необходимо также просмотреть рендеры всех страниц и слайдов.
